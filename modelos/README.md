# Modelos de voz

Aquí se guardan los modelos que `herramientas/audio.py` baja la primera vez que transcribe:

- Whisper large-v3-turbo (814 MB), el modelo preciso;
- Whisper small (484 MB), si alguna vez se pide el modelo rápido;
- el modelo de huellas de voz para separar hablantes (40 MB).

No hace falta abrir ni tocar esta carpeta. Si en tu computadora no se pueden bajar, copia
aquí la carpeta `modelos/` de un compañero que ya los tenga.
